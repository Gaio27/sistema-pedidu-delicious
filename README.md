## 📖 Kona-ba Restoran Delicious PWA

**Restoran Delicious PWA** mak sistema dijitál ba pedidu hahan no hemu (*dine-in ordering system*) bazeia ba **Progressive Web Application (PWA)** ne'ebé dezenvolve espesifikamente ba **Restoran Delicious**.

Sistema ne'e fasilita kliente sira atu scan QR Code dinámiku iha kada meja, haree lista menu ho lian Tetun, hili variante hahan, no haruka pedidu direta husi smartphone la presiza download aplikasaun husi Play Store ka App Store.

Plataforma ne'e integra **Cashier Verification Gate** (*gerbang verifikasi kasir*) ne'ebé estritu atu asegura katak pedidu hotu tenke hetan validasaun husi kasir antes tama ba koziña (KDS), prevene pedidu falsu ka spam, jestaun split-bill no troka osan iha moeda Dólar Amerikanu (USD $), no sinkronizasaun dadus *real-time* liu husi WebSockets.

---

## 🚀 Kapasidade Prinsipál

- 📱 **PWA Support**: Bele instala iha smartphone (Android/iOS) no sevisu bele la'o offline.
- 📋 **Menu Dijitál ho Lian Tetun**: Mapeamentu kategoria hahan, hemu, no sobremesa.
- ⚡ **Real-time Order**: Sinkronizasaun pedidu diretu ba kasir no koziña.
- 🔒 **Verifikasaun Kasir**: Pedidu hotu passa liu verifikasaun kasir antes kria no te'in.
